Fingerprint Protection Guide

Understand how AutoGuard keeps your profiles undetectable — so you can pick the right settings.

Every browser profile in AutoGuard gets a unique digital fingerprint. The system randomizes over 100+ parameters including Useragent, WebGL, Canvas, Fonts, Audio context, Screen resolution, and Hardware concurrency. Below is a breakdown of the fingerprinting layers — all fully configurable per profile.

🎨

Canvas & WebGL Fingerprinting

Prevents image‑based tracking by injecting subtle noise into canvas and WebGL renders.

  • Canvas Noise 4 levels of randomization · preserves image quality
  • WebGL Vendor Spoofs GPU vendor, renderer, and driver info
  • WebGL Parameters Alters max texture size, shader precision, and more
  • Canvas Bloat Adds extra pixels to canvas output (undetectable)
🔤

Font & System Fingerprinting

Controls which fonts and system metrics are exposed to websites.

  • Font List Randomizes installed font list per profile
  • System Fonts Spoofs system font fallbacks and metrics
  • Screen Resolution Customizable width, height, and color depth
  • Timezone & Locale Spoofs timezone, language, and region settings
🎧

Audio & Media Fingerprinting

Prevents audio‑based tracking by altering audio context output and media device lists.

  • Audio Context Adds frequency distortion to audio fingerprint
  • Media Devices Spoofs camera, microphone, and speaker lists
  • Codec Support Randomizes supported audio/video codecs
💻

Hardware & Browser Fingerprinting

Controls the hardware and browser‑level parameters that websites inspect.

  • User Agent Full UA spoofing with version randomization
  • Hardware Concurrency Spoofs CPU core count and memory
  • Platform & OS Spoofs operating system and platform
  • WebRTC Prevents IP leaks through WebRTC
✨

Not sure which settings to use?

Leave the profile on Auto (Balanced) — AutoGuard automatically selects the optimal fingerprint parameters for your target websites and proxies.
